# Client for [AI Pets](../)

The React/Vite client uses Firebase Google sign-in and the [AI Pets server](../server) for
membership, coupon redemption, token balance, and Gemini chat. Entity (pet) state remains
in the browser's local storage and synchronized with the server when applicable.

For setup instructions, refer to the [SETUP.md](../SETUP.md) file.

## Main Features

- Google sign-in via Firebase
- Full CRM (coupon, token, etc.) services through the [AI Pets server](../server)
