# Client

The React/Vite client uses Firebase Google sign-in and the AI Pets server for
membership, coupon redemption, token balance, and Gemini chat. Pet state remains
in the browser's local storage and synchronized with the server when applicable.

For setup instructions, refer to the [SETUP.md](./SETUP.md) file.

## Main Features

- Google sign-in via Firebase
- Membership management through the AI Pets server
- Coupon redemption
- Token balance display
- Gemini chat integration
- Local pet state synchronized with the server
