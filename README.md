# AI Pets

![AI Pets Logo](./client/dist/favicon.svg)

Full-stack virtual entity project powered by Gemini AI technologies. You may call it AI Buddy, AI Companion, AI Friend, AI Pal or whatever you like.

## Overview

AI Pets is a VIRTUAL ENTITY (VE) project, designed to create intelligent virtual companions for users using Super/Artificial Intelligent (SI/AI) technologies. The project aims to enhance user empathy and engagement through these intelligent interactions.

## Full-stack Architecture

The AI Pets project is designed with a full-stack architecture, encompassing both front-end and back-end components to deliver a seamless user experience.

### Front-end (/client)

- User interface for interacting with virtual pets
- Real-time updates and notifications
- Multi-platform support (web, mobile, etc.)
- Augmented reality (AR) support for immersive pet interactions

### Back-end (/server)

- API endpoints for client interactions
- Membership and coupon management
- Token balance tracking
- Gemini chat integration
